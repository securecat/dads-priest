# アクセシビリティ

最終更新：2026-11-25

## 優先事項と目標

DADS Priestプロジェクトの成果物はYouTubeで公開する楽曲づくりであるため、本リポジトリで目標とするアクセシビリティの基準はありません。

## 対応している環境

- DADS Priestの各楽曲は、YouTubeを閲覧可能な環境で利用できます。

## 既知の制限

現在、把握している制限はありません。

## アクセシビリティの問題を報告する

本リポジトリにおいて解決すべき事項であれば、[GitHub Issues](https://github.com/securecat/dads-priest/issues) で報告してください。日本語でも英語でも構いません。

## 責任者と保守

この文書は、メンテナーの securecat が管理しています。機能を追加したときや、動作を確認した環境が変わったときに更新します。

## この文書へのフィードバック

この文書やアクセシビリティへの取り組み方についての提案も、[GitHub Issues](https://github.com/securecat/dads-priest/issues) で受け付けています。
