# YELLOW & BLACK ―誰一人取り残されない―

DADS Priest のデビュー曲。

## テーマ

基本デザイン「カラー」にある、フォーカスインジケーターの色の規定が軸。

> フォーカスインジケーターのカラーです。Yellow-300とBlackの2重構造をもち視認性を確実にします。いかなる場合も変更してはいけません。

サビにはデジタル庁のミッション「誰一人取り残されない」を掲げる。ヴァースでは、コントラスト・カルーセル・フォーム・リンクテキストといった現場でよくある失敗を取り上げる。Breakdown は WCAG 2.2 の達成基準番号のコール＆レスポンス。

## スタイル

```
Epic classic heavy metal with requiem atmosphere, mid-tempo 120 BPM, crushing palm-muted riffs, twin harmonized lead guitars, thunderous double bass drums, powerful operatic high-pitched male vocals with piercing screams, solemn whispered prayers, grand pipe organ, epic wordless choir, gang chants, heavy breakdown with harsh vocals, soaring melodic guitar solo, solemn anthemic clean bridge, key change into triumphant final chorus, majestic, dark, heroic, Japanese lyrics
```

Exclude Styles：

```
pop, lo-fi, acoustic, soft, ballad, fast, punk
```

## 元ネタ

| 歌詞 | 出典 |
|---|---|
| Intro の「こちら」と呼ばれ／Pre-Chorus 2 の「ここ」「こちら」 | 基本デザイン「リンクテキスト」：「ここ」や「こちら」をリンクテキストにしない |
| よんてんご たい いち／大きな文字でも言い訳は許さない | 基本デザイン「カラー」：WCAG には大きな文字なら 3:1 でよいという例外があるが、DADS はそれを使わず、文字の大きさに関わらず 4.5:1 以上を確保している |
| ドロップシャドウ／さんたいいちの つるぎ／強制カラー | 基本デザイン「エレベーション」：ドロップシャドウでコントラスト比を確保することはできない。3:1 以上のボーダーを付ける。強制カラーモードへの配慮 |
| タブを叩け 居場所を照らせ | キーボード操作では、フォーカスインジケーターが現在地を示す唯一の手がかり |
| YELLOW AND BLACK／二重の結界／いかなる場合も変えてはならない | 基本デザイン「カラー」：フォーカスインジケーターは Yellow-300 と Black の 2 重構造。いかなる場合も変更してはいけない |

| 誰一人 取り残されない／NO ONE LEFT BEHIND | デジタル庁のミッション「誰一人取り残されない、人に優しいデジタル化を。」 |
